# Build discipline

- Create only what I asked for. Don't add extra pages, features, files, packages or settings.
- If you have a better idea, suggest it first and wait for my answer before building it.
- Don't overcomplicate or overthink. Choose the simplest solution that works.
- Reuse existing components before creating new ones.
- Don't refactor or change code that is unrelated to the task.
- Ask before installing any new dependency.

## Hackathon mode
- We have 4 hours. A working, demo-ready flow matters more than perfect code.
- Build the main flow end to end first, then polish.
- Use realistic sample data so the demo looks real.
- Keep the app runnable at all times. Don't leave it broken between tasks.
- Work in small steps and update [TASKS.md](TASKS.md) after each one.
